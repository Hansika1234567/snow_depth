# Data

The original dataset is **not included** in this repository due to its size.

## Expected File

**Filename:** `final_dataset_without_modis_with_features.csv`  
**Expected location:** `data/final_dataset_without_modis_with_features.csv`

## How to Use

1. Obtain the dataset separately.
2. Place the CSV file in this `data/` folder.
3. The pipeline expects it at the path: `data/final_dataset_without_modis_with_features.csv`

The dataset contains approximately 224,267 samples with geospatial, terrain, environmental, and temporal features used for snow depth estimation.
